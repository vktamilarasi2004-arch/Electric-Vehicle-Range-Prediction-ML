# Electric-Vehicle-Range-Prediction-ML
This project focuses on predicting the driving range of Electric Vehicles (EVs) using Machine Learning techniques by leveraging the EV Range Prediction dataset from Kaggle. With the rapid global transition towards clean mobility and sustainable energy solutions, accurately estimating the range of an electric vehicle has become extremely important. EV users often face “range anxiety,” which means the fear of running out of battery before reaching a charging station. This project aims to address that challenge by building a reliable ML model that can estimate how far an EV can travel under different conditions.

The dataset used in this project contains features such as speed, temperature, battery percentage, distance covered, driving style, and environmental conditions, all of which significantly affect the actual driving range. The project begins with data cleaning and preprocessing, where missing values, duplicates, and irrelevant attributes are handled. After that, Exploratory Data Analysis (EDA) is carried out to understand the relationship between features, detect patterns, and visualise key insights through graphs and plots.

Multiple Machine Learning algorithms such as Linear Regression, Random Forest Regressor, XGBoost Regressor, and Gradient Boosting were applied and compared to identify the best-performing model. Feature scaling techniques like StandardScaler were applied, and the dataset was split into training and testing portions to evaluate the model’s accuracy. The model’s performance was assessed using metrics such as Mean Absolute Error (MAE), Mean Squared Error (MSE), and R² score.

The primary objective of this repository is to provide a complete end-to-end solution for EV range prediction. The project includes the dataset, Google Colab notebook, trained model files, and visualisations. This makes the repository helpful for students, researchers, and developers interested in Electric Vehicles, Data Science, and Machine Learning.

This project was created as part of my internship submission, and it showcases practical ML skills such as dataset handling, model training, evaluation, and deployment-ready structuring. The repository provides a simple, clear, and effective approach to predicting EV driving range using real-world data, helping contribute towards smart mobility and sustainable technology development.
